# Portfolio de Testing QA

¡Bienvenidos a mi portafolio! 👋

Este repositorio reúne mis primeras prácticas y proyectos de **aseguramiento de la calidad de software (QA)**. Su objetivo es documentar lo que voy aprendiendo y mostrar cómo analizo requisitos, diseño pruebas, registro defectos y comunico resultados.

## Formación
- Testing QA de Software — Instituto Web.
- Tester QA — Talento Tech.

## Conocimientos y herramientas
- Testing manual y funcional; pruebas positivas y negativas.
- Análisis de requerimientos y criterios de aceptación.
- Técnicas de caja negra: partición de equivalencia y análisis de valores límite.
- Diseño y gestión de casos de prueba con **Jira y Zephyr Essential**.
- Reportes de defectos, severidad y prioridad.
- Testing de APIs con **Postman**.
- Pruebas responsive con **Chrome DevTools**.
- Métricas de cobertura e informes de testing.

## Mi objetivo
Continuar desarrollándome en **QA funcional**, fortalecer el análisis de riesgos y la documentación de pruebas, y aprender progresivamente herramientas de automatización.

> Este es un portafolio de aprendizaje. Los casos, resultados y evidencias se documentarán diferenciando lo diseñado, lo ejecutado y lo efectivamente observado. No se publicarán credenciales, datos personales de terceros ni información interna sin autorización.
